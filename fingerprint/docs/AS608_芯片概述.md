# AS608 芯片概述

> 提取自《AS608 数据手册 V1.07》，仅保留与项目相关的关键参数。

## 芯片简介

AS608 是杭州晟元（Synochip）推出的高性能 32 位微控制器，基于 ARM Cortex-M 内核，专为指纹识别应用设计。内嵌 512KB Flash、128KB SRAM、指纹算法单元和多种加解密引擎，适用于指纹模块的单芯片解决方案。

## 关键电气参数

| 参数 | 值 |
|------|-----|
| 内核电压 | 1.8V ± 5% |
| I/O 电压 | **3.3V ± 10%** |
| 工作温度 | -40°C ~ 85°C（主频 < 128MHz） |
| 工作主频 | 最高 144MHz（内部环振） |
| 动态功耗 | < 30mA @ 144MHz |
| 休眠功耗 | < 200µA |

## 供电说明

芯片内置 3 个 LDO：

| LDO | 输入 | 输出 | 最大电流 |
|-----|------|------|---------|
| LDO5033 | 5V | 3.3V | 250mA |
| LDO3318 | 3.3V | 1.8V | 150mA |
| LDO1812 | 1.8V | 1.2V | 100mA |

> **Nexys4 DDR PMOD 直出 3.3V**，可直接供电给 AS608 模块。无需外接 5V 电源。

## 通信接口

| 接口 | 数量 | 项目用途 |
|------|------|---------|
| UART | 2 | **与 FPGA 通信**（57600 bps, 8N2） |
| USB 2.0 | 1 | 未使用 |
| SPI | 2 | 未使用 |
| I2C | 1 | 未使用 |

## 存储资源

| 存储 | 容量 | 用途 |
|------|------|------|
| Flash | 512KB | 固件 + 指纹模板库 |
| SRAM | 128KB | 运行时数据 |
| OTP | 1KB | 一次性编程区 |

## 指纹相关规格

- 内嵌指纹算法（ROM 驻留）
- 图像缓冲区：72KB
- 特征文件：256 字节 / 个
- 模板：512 字节 / 个（两个特征合成）
- 指纹库容量：根据外挂 Flash 大小自动判别
- 安全等级：5 级可调
